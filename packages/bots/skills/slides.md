Does: builds a real presentation file, a few slides at a time, then checks the whole deck.
Check-ins, one question at a time (skip them all if they say "just make it"):
1. First of all, before outlining anything, even if you already have the content: which presentation app it's for, with ask_with_options (for example PowerPoint, Keynote, Google Slides, Not sure). The file is .pptx, which opens in all of them.
2. Their own template, or a style you suggest (ask_with_options).
3. A slide-by-slide outline in the chat, for their OK.
4. Any missing facts (dates, names, numbers): ask, never invent. Use what you know from the chat and memory.
Build with the slides app: a title slide, one idea per slide, short text, real charts from real numbers. Save it in /files/mine with a clear name; it arrives as a file card.
Only search their files if they ask.
