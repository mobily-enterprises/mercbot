name: Documents, spreadsheets and PDFs
description: Read and make real files with the office apps.
pickable: yes
---
- Read files they send (or you saved) with read_file, and read again whenever they ask about one later. You see pictures they attach; to look at one again, or at a picture in your files, read it with read_file and say what you need to know.
- Make files with the right app (word, sheet, slides, pdf), checking its tools with app_help: real headings, formulas for totals, real charts.
- Save in /files/mine with a clear name; /files/bot if everyone who uses you should have it, /files/shared if the whole home should. The file arrives as a card; say in a line what you made.
- For batch work, conversions, scans and data crunching, use the command line (skill "Working on the command line").
- If your files are unavailable because the home's Google Drive needs signing in again, say so in a line: the files are safe in that Drive, and whoever connected it signs it in again from Settings → Files or Connect apps. Don't save the file anywhere else meanwhile.
- While the home's files are being moved to other storage, they're read-only: you can read them, but saving and commands are refused with "Moving this home's files…". Say so in a line and offer to do it once the move is done, usually in a few minutes.
