# Contributing to Mercbot

Thank you for helping. Open an issue to report a problem or discuss an idea, or a pull request against `main` with
your change. `npm run verify` should pass before you ask for a review, and a change to what Mercbot does updates the
explanation in `genesis/` and the help in `help/` with it.

## Signing the Contributor License Agreement

Before a pull request can be merged, everyone who wrote commits in it signs [CLA.md](CLA.md) with Gigsnet Pty Ltd,
once. When you open your first pull request, the CLA Assistant bot comments with a link to the agreement. Read it,
then sign by adding this comment to the pull request, exactly:

    I have read the CLA Document and I hereby sign the CLA

The bot records your GitHub account, the pull request and the time in `signatures/cla.json` on this repository's
`cla-signatures` branch, and your later pull requests need nothing more. Comment `recheck` if the check doesn't
update.

Contributing for yourself, you sign the Individual agreement. Contributing for your employer or another organisation,
you sign the Entity agreement on its behalf: first comment with the organisation's name and your title in it, which
confirms you may sign for it, then add the sentence above.

## Work you don't own

Submit only work whose copyright you (or, for the Entity agreement, your organisation) own. If part of a pull
request is someone else's work, such as copied code or an image, say so in the pull request: name its author, where
it comes from and its licence. It is then not a Contribution under the agreement, and is included only if its licence
allows it.
