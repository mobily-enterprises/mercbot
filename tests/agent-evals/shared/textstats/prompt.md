In this folder, write a Python module textstats.py with two functions:
- word_count(text): the number of words, where a word is a run of letters, digits or apostrophes; case-insensitive.
- top_words(text, n): the n most common words as a list of (word, count) pairs, lowercased, most common first, ties broken alphabetically.
Also write your own tests in test_textstats.py using unittest, run them with `python3 -m unittest`, and keep going until they pass. Use only the Python standard library.
