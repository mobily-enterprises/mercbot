Write ranges.py with a function merge_bookings(bookings) that takes a list of (start, end) date strings in YYYY-MM-DD form (inclusive on both ends) and returns the merged list of non-overlapping ranges, sorted by start. Ranges that overlap OR touch (one ends the day before the next starts) merge into one. Invalid input (end before start, or a bad date) raises ValueError. Write unittest tests, run them, and keep going until they pass. Standard library only.
