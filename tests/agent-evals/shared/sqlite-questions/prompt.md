shop.db in this folder is a SQLite database of customers and orders. Answer these and write the answers to answers.json with these keys:
- "orders_au": how many orders came from customers in Australia (country AU);
- "top_customer": the name of the customer with the highest total spend;
- "busiest_month": the month (YYYY-MM) with the most orders;
- "avg_order_nz": the average order total for New Zealand customers (NZ), rounded to 2 decimals.
